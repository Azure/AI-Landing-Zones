    AI Landing Zones

    AI Landing Zones provides reference architectures and deployable implementations for secure, resilient AI applications and agents on Azure. Choose Agent Landing Zone, AI Gateway Landing Zone, or both.

    Architecture

    An application landing zone that can be deployed with or without an existing Azure platform landing zone.

    Implementation

    Bicep and Terraform implementations built on Azure Verified Modules.

    Workloads

    A foundation for generative and non-generative AI workloads, focused on AI on Azure Platform.

    Note

    Designed and tested for Azure public cloud. Validate government and sovereign deployments separately. Some included services may be in preview.

    Use cases

    Build AI applications and agents on a secure Azure foundation for scenarios such as:

    Use case Example scenario
    Knowledge assistants Help employees find answers in organizational policies, procedures, and technical documentation.
    Document processing Extract, classify, and summarize information from invoices, contracts, and reports.
    Business process agents Coordinate tasks across business systems, such as handling service requests and approval workflows.

    Reference Architectures

    Agent Landing Zone

    Agent Landing Zone provides an Azure foundation for AI applications and agents, with a default application built on Microsoft Foundry. Deploy the infrastructure, the application, or both using the Agent Landing Zone guide.

    AI Gateway Landing Zone

    AI Gateway Landing Zone provides a shared gateway for AI applications and agents, using Azure API Management to centrally manage access to Microsoft Foundry models. Choose a Bicep or Terraform implementation below.
