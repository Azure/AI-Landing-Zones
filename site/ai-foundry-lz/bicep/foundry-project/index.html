    Parameters

    Required parameters

    Parameter Type Description
    accountName string Name of the existing parent Foundry Account resource.
    createAccountCapabilityHost bool Whether to create the capability host for the Foundry account. Requires associated resource connections to be provided.
    createProjectCapabilityHost bool Whether to create the capability host for the Foundry project. Requires associated resource connections to be provided.
    name string The name of the AI Foundry project.

    Optional parameters

    Parameter Type Description
    aiSearchConnection object Azure Cognitive Search connection for the project.
    cosmosDbConnection object Azure Cosmos DB connection for the project.
    desc string The description of the AI Foundry project.
    displayName string The display name of the AI Foundry project.
    location string Specifies the location for all the Azure resources.
    lock object The lock settings of the service.
    storageAccountConnection object Storage Account connection for the project.
    tags object Tags to be applied to the resources.
